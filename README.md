# tanmayee043.github.io

My portfolio, built with [Astro](https://astro.build) and deployed to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

Project write-ups and the validator demo are in `src/pages/index.astro`. Design decisions are in [`DESIGN.md`](DESIGN.md).
